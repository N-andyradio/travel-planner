# 국내 여행 추천 프로그램

Gemini API와 Kakao Local API를 연동하여 만든 국내 여행지 추천 CLI 프로그램입니다. 여행하고자 하는 날짜를 입력하면 해당 시기에 방문하기 좋은 국내 도시를 추천받고, 그 지역의 맛집 정보를 자동으로 검색한 뒤, 두 결과를 종합한 여행 리포트를 생성합니다.

단순히 API를 한 번 호출하고 끝나는 것이 아니라, LLM의 출력을 구조화된 데이터(JSON)로 받아서 다음 단계인 지도 검색 API의 입력으로 다시 사용하고, 그 결과를 다시 LLM에게 넘겨 최종 결과물을 만들어내는 파이프라인 형태로 구성했습니다.

## 프로그램 개요

이 프로그램은 아래 세 가지 API 호출을 순서대로 엮어서 하나의 결과물을 만들어냅니다.

- **Gemini API (1차 호출)**: 입력받은 날짜를 기준으로 여행하기 좋은 국내 도시 한 곳과 해당 시기의 날씨, 행사/축제 정보, 추천 이유를 JSON 형식으로 생성합니다.
- **Kakao Local API**: 위에서 추천받은 도시를 키워드로 사용해 그 지역의 맛집 정보를 검색합니다.
- **Gemini API (2차 호출)**: 1차 추천 결과와 맛집 검색 결과를 종합하여, 사람이 읽기 좋은 형태의 Markdown 여행 리포트를 작성합니다.

실제 여행 정보의 정확도보다는, 여러 API를 연결해서 데이터를 구조화하고 다음 단계로 넘기는 흐름 자체에 초점을 맞춰 구현했습니다.

## 동작 흐름

```
사용자 입력 (-date "YYYY-MM-DD")
        │
        ▼
[1/3] Gemini API 호출
      → recommended_city, weather, events, reason (JSON)
        │
        ▼
[2/3] Kakao Local API 호출 (recommended_city 기준 맛집 검색)
      → 맛집 리스트 (JSON, 0건 가능)
        │
        ▼
[3/3] Gemini API 호출 (위 결과 종합)
      → 최종 여행 리포트 (Markdown)
        │
        ▼
results/ 폴더에 JSON 파일과 MD 파일로 저장
```

## 설치 및 실행 방법

### 1) 필요한 패키지 설치

Python 3.10 이상 환경에서 아래 명령어로 의존성을 설치합니다.

```bash
pip install -r requirements.txt
```

사용하는 주요 패키지는 다음과 같습니다.

- `requests` : Gemini API 및 Kakao Local API에 HTTP 요청을 보내는 데 사용
- `python-dotenv` : `.env` 파일에 저장된 API 키를 환경변수로 불러오는 데 사용

### 2) 프로그램 실행

```bash
python travel_planner.py -date "2026-03-15"
```

`-date` 옵션은 필수이며, 반드시 `"YYYY-MM-DD"` 형식으로 입력해야 합니다. 형식이 올바르지 않을 경우 프로그램은 사용법을 안내하고 즉시 종료됩니다.

정상적으로 실행되면 아래와 같은 진행 로그가 순서대로 출력됩니다.

```
[1/3] 1차 추천 생성 중(Gemini)...
  - recommended_city: "제주"
[2/3] 맛집 검색 중(Kakao Local)...
  - 맛집 5곳 검색 완료
[3/3] 최종 리포트 생성 중(Gemini)...
  - 리포트 생성 완료

완료! results/2026-03-15_travel_plan.md 를 확인하세요.
원본 데이터: results/2026-03-15_travel_data.json
```

## API 키 발급 및 설정

이 프로그램은 API 키를 코드에 직접 작성하지 않고, `.env` 파일을 통해 환경변수로 관리합니다. 이는 실수로 키가 외부에 노출되는 것을 막고, 키가 바뀌더라도 코드를 수정할 필요가 없게 하기 위함입니다.

### 설정 절차

1. 저장소에 포함된 `.env.example` 파일을 복사하여 `.env` 파일을 생성합니다.

   ```bash
   cp .env.example .env
   ```

2. 생성된 `.env` 파일을 열어 아래와 같이 본인이 발급받은 실제 키 값을 입력합니다.

   ```
   GEMINI_API_KEY="발급받은_제미나이_키"
   KAKAO_API_KEY="발급받은_카카오_REST_API_키"
   ```

### 키 발급 방법

**Gemini API 키**
- https://aistudio.google.com/apikey 에서 발급받을 수 있습니다.

**Kakao REST API 키**
- https://developers.kakao.com 에서 애플리케이션을 생성한 뒤, "앱 키" 메뉴에서 확인할 수 있습니다.
- 여러 종류의 키(네이티브 앱 키, JavaScript 키, Admin 키 등)가 함께 표시되는데, 이 중 반드시 **REST API 키**를 사용해야 합니다.
- Kakao Local API 호출을 위해서는 해당 애플리케이션의 "제품 설정 > 카카오맵" 메뉴에서 사용 설정이 활성화되어 있어야 합니다. 활성화되어 있지 않으면 401 또는 403 오류가 발생합니다.

## 결과물 구조

실행이 완료되면 `results/` 폴더에 아래 두 개의 파일이 생성됩니다.

**`{날짜}_travel_data.json`**

1차 추천 결과, 맛집 검색 결과, 발생한 오류 목록을 모두 포함한 원본 데이터입니다.

```json
{
  "date": "2026-03-15",
  "recommendation": { "recommended_city": "...", "weather": "...", "events": [...], "reason": "..." },
  "restaurants": [ { "name": "...", "address": "...", "category": "...", "url": "...", "x": ..., "y": ... } ],
  "errors": []
}
```

**`{날짜}_travel_plan.md`**

최종 여행 리포트로, 아래 항목들로 구성됩니다.

- 추천 지역 / 추천 이유
- 날씨 요약
- 행사 및 축제 목록
- 맛집 추천 (검색 결과가 없을 경우 "데이터 없음"으로 표기)
- 1일 일정 제안
- 오류 요약 (실행 중 발생한 오류가 있을 경우 기록)

## 에러 처리 방식

과제 요구사항에 따라, 외부 API 호출 과정에서 발생할 수 있는 여러 오류 상황에 대해 프로그램이 중단되지 않고 계속 진행되도록 구현했습니다.

- **API 키 미설정**: 프로그램 시작 시 즉시 감지하여 종료하고, 설정 방법을 안내합니다.
- **날짜 형식 오류**: 사용법을 출력하고 종료합니다.
- **Kakao Local API 실패** (네트워크 오류, 인증 실패, 쿼터 초과 등): 맛집 섹션을 "데이터 없음"으로 처리하고, 나머지 리포트 생성은 정상적으로 진행합니다.
- **맛집 검색 결과 0건**: 오류로 취급하지 않고 "데이터 없음"으로 처리한 뒤 다음 단계로 진행합니다.
- **Gemini JSON 파싱 실패**: 프롬프트를 조정하여 최대 1회 재시도하며, 재시도까지 실패할 경우 기본값으로 대체하여 진행합니다.

발생한 모든 오류는 내부적으로 리스트에 누적되며, 최종적으로 `results/*.json`의 `errors` 배열과 Markdown 리포트 하단의 "오류 요약" 섹션에 함께 기록됩니다.

## 보안 관련 주의사항

- API 키는 코드, README, 커밋 메시지, 로그 등 어디에도 직접 작성하지 않습니다.
- `.env` 파일은 `.gitignore`에 등록되어 있어 Git 저장소에 포함되지 않습니다.
- 협업이나 공유 과정에서 키가 노출되지 않도록 항상 `.env.example`만 공유하고, 실제 키 값이 담긴 `.env` 파일은 개인 환경에만 두어야 합니다.

## 프로젝트 구조

```
travel_planner/
├── travel_planner.py      # 메인 프로그램
├── requirements.txt        # 필요 패키지 목록
├── .env.example             # 환경변수 예시 파일
├── .gitignore                # .env 등 커밋 제외 대상 설정
├── README.md                # 프로젝트 설명 문서
└── results/                  # 실행 결과가 저장되는 폴더
    ├── {날짜}_travel_data.json
    └── {날짜}_travel_plan.md
```
